# heko – תבניות הצעות מחיר | Orit Lev Architect

בתיקייה `תבניות הצעות מחיר` יש 3 תבניות Word בעיצוב אחיד:

| קובץ | מתי משתמשים |
|---|---|
| תבנית 1 - שינויי דיירים.docx | דירה חדשה מקבלן – שינויי דיירים, נגרות ומטבח |
| תבנית 2 - שיפוץ.docx | שיפוץ בנכס קיים – מחיר נפרד לכל שלב |
| תבנית 3 - רישוי היתר.docx | ליווי רישוי עד קבלת היתר בנייה |

## איך מכינים הצעה חדשה (בערך 10 דקות)
1. פותחים את התבנית המתאימה ושומרים מיד בשם חדש ("שמירה בשם…"), למשל: `הצעת מחיר - כהן - רמת גן.docx`.
2. עוברים על כל מה שמסומן **בצהוב** ומשנים לפרטי הלקוח (תאריך, שם, כתובת, גודל, פריטי נגרות, מחיר).
3. בטבלת התשלומים – מעדכנים את הסכומים לפי שכר הטרחה החדש (אחוז × סכום כולל).
4. מוחקים שורות שלא רלוונטיות, ומורידים את הסימון הצהוב (בחירת הכל → "צבע הדגשה" → ללא צבע).
5. שומרים כ-PDF ושולחים ללקוח.

## שינוי קבוע בכל התבניות
הטקסט והעיצוב נוצרים מהקובץ `tools/build_templates.js`. שינוי של סעיף קבוע (למשל התעריף השעתי – כרגע 380 ₪) נעשה שם פעם אחת, ואז מריצים:

```
node tools/build_templates.js
```

## טופס אוטומטי
דף אינטרנט שבו ממלאים את פרטי הלקוח והמחיר, רואים את ההצעה מתעדכנת, ומורידים קובץ Word מוכן:
https://claude.ai/artifact/23xuZvs9MihPCT114gwvzE

הקוד נמצא ב-`tools/quote-form`: `quote-core.js` (נוסח ההצעה ובניית הקובץ), `page.html` (הטופס).
אחרי שינוי מריצים `python3 tools/quote-form/build.py` כדי ליצור מחדש את `index.html`.
